## 6. Mapping to the rebuild

The original is a large, multi-feature product. The rebuild charter scopes the **first releasable slice**
(auth → identity → content → moderation → Android shell → feature integration) and defers
chat, audio rooms, and payments to later compliance-gated work packages.

This static evidence supports WP0/WP1: it confirms the *feature surface* (login, anonymous
personas, feed, topics, posts, comments, reports, blocks, settings, safety modes) without
reusing any original code. The later slices (IM, audio live, flash chat, wallet) are evidenced
here so their eventual work packages can size the effort.
